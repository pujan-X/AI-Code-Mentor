# 🚀 AI Code Mentor

**Your personal AI-powered coding assistant that explains logic, fixes bugs, and optimizes performance.**

### 🔗 [Live Demo](https://ai-code-mentor.netlify.app/)
*(Note: The backend is hosted on a free instance. Please allow ~50 seconds for the server to wake up on the first request.)*

---

## 📖 About The Project

**AI Code Mentor** is a full-stack application designed to help developers understand and improve their code. Unlike standard linters, it uses the **Google Gemini 2.5 AI** model to provide deep insights, including:
* **Logic Explanation:** Breaks down complex code into simple terms.
* **Complexity Analysis:** Automatically calculates Big O Time & Space complexity.
* **Smart Refactoring:** Rewrites code for better performance and readability.

Built with a **Java Spring Boot** backend and a responsive **Glassmorphism UI**.

---

## ✨ Key Features

* **🤖 AI-Powered Analysis:** Leverages Google's Gemini 2.5 model for high-accuracy debugging.
* **⚡ Performance Metrics:** Instant Big O analysis (Time & Space complexity).
* **🛠️ Automated Refactoring:** Generates cleaner, optimized versions of your code.
* **🎨 Modern UI:** A distraction-free, glassmorphism-inspired interface with syntax highlighting.
* **☁️ Cloud Native:** Dockerized backend deployed on Render; Frontend on Netlify.
